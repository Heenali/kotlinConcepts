Context Preservation(flowOn)-----------------------------

- Flow Preser the context. Ex if the Consusmer run on main tread then producer automatically runs on main thread only
Or in another words collect and emit run on same thread
 
if you want to run on diffrent thread then you need to inform to flow using .flowOn

Ex- .flowOn(Dispatcher.IO)
code of line writen after the flowOn will run on main thread
code of line writen before the flowOn will run on Dispatcher.IO

- we can use multiple .flowOn with single collect
